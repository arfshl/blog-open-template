## Blog Open Template

Free version of arfshl/blog codebase, licensed under BSD-3-Clause License

Supports most feature of GitHub Flavored Markdown, Pagination per post history, per tags (multiple tags in 1 article is allowed too) and per category

This is, mainly used with [pagescms](https://pagescms.org/) but can also used with another setups

Using [Giscus](https://giscus.app/) for commenting platform, click [here](https://giscus.app/) to set up your own, and put generated `<script>` on `src/plugins/giscus.astro`

Preview: https://arfshl.github.io/blog-open-template
